Clean Block is an Open Sourced Ad Blocker changes will be made 

how to use it?

download the latest version in releases

then right click the .zip and click "extract here"  just extracting will not work!

next go to go to chrome://extensions or brave://extensions and turn developer mode on 

next press on "load unpacked" and choose the folder named CleanBlock-x.x.x make sure it is the folder not the .zip

if you have done everything right the extension should pop up 

i recommend pinning the extension for easy access

next press your extensions icon on your browser and click the 3 dots on CleanBlock and press on "inspect popup" you will see a box appear 

if you see a devtools box appear simply click on cleanblock again to close it 

Have fun!
